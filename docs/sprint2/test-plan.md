# План тестування продукту «ШопЛайн»

**Продукт:** «ШопЛайн» | **Спринт:** 2 | **Дата:** 28.09.2026 | **Автор:** Прохоренко М. (Інженер з тестування)

## 1. Продукт і межі тестування
Об'єктами тестування у версії 1.0 є два окремі компоненти:
1. **Demo-застосунок (Web):** practicesoftwaretesting.com (каталог, кошик, оформлення замовлення, особистий кабінет).
2. **Java-бібліотека (Модуль бізнес-логіки):** класи `Cart`, `DiscountCalculator`, `PromoCodeValidator`.

Тестування адміністративної панелі та нарахування бонусних балів наразі виключено з меж тестування (поза обсягом v1.0).

## 3. Ризики та припущення
- **Ризик скидання даних:** Оскільки база даних Demo-застосунку періодично скидається іншими користувачами, тестові дані (користувачі, замовлення) можуть зникати під час тривалих тестів. Усі тест-кейси мають створювати передумови з нуля.
- **Асинхронність SPA:** Інтерфейс Angular (SPA) підвантажує елементи динамічно. Для автоматизації GUI-тестів у майбутньому потрібно використовувати явні очікування (Explicit Waits), щоб уникнути хибних падінь.
