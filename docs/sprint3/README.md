## 5. Середовище та обмеження тестування

- Demo: [https://practicesoftwaretesting.com](https://practicesoftwaretesting.com).
- За журналом виконання: Google Chrome 140.0 (64-bit), Windows 11, роздільність 1920×1080.
- Demo періодично скидає тестові дані; тест-кейси використовують визначені тестові дані та не мають залежати від попередніх прогонів.
- Реальна оплата у demo не виконується.
- Для окремої Java-бібліотеки перевірки винятків, округлення та промокодів мають виконуватися модульними тестами.
- На публічному demo не виконуються атаки, перебір паролів, навантажувальні запити чи інші дії, що можуть вплинути на сторонніх користувачів.

## 6. Висновок

У Sprint 3 підготовлено та прорецензовано 43 тест-кейси, налаштовано GitHub Issues і створено реєстр відкритих дефектів. У журналі `Run 1` зафіксовано 15 виконань: 6 Passed та 9 Failed. Покриття бізнес-логіки, окремих нефункціональних вимог та документації, які не можна повноцінно перевірити через публічне demo, визначено окремо з поясненням обмежень і подальших перевірок.
