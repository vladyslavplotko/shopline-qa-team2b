## Питання для узгодження під час реалізації

1. **BL-20 та BL-30 частково дублюються в SRS-1.1.** Обидві вимоги описують повторне додавання того самого SKU та збільшення кількості. У матриці BL-20 окремо покриває обмеження 99 і відмову без зміни стану; BL-30 — відсутність дубльованого рядка. Якщо README модуля визначає інше розділення, оновити матрицю за його контрактом.
2. **BL-80: використання коду в «будь-якому іншому інтернет-магазині».** Це можна автоматизувати лише якщо відповідний стан/правило доступні в моделі модуля. Перевірити README та клас `PromoCode`; якщо даних/методу для цього немає, зафіксувати питання для KT/розробника, а не вигадувати спосіб перевірки.
3. Усі назви методів у колонці тестів — план. Перед написанням коду звірити реальні сигнатури `Cart`, `DiscountCalculator`, `PromoCodeValidator` і `PromoCode` у `code/modules/shopline/v1`.
