# Модуль бізнес-логіки «ЕдуПортал» — версія 1.0.0

Java-модуль продукту П6 «ЕдуПортал» (система дистанційного навчання) для спринта 4
«Автоматизація: JUnit 5». Модуль реалізує правила розділу 5 «Вимоги до бізнес-логіки»
специфікації `SRS_06_ЕдуПортал.html` (вимоги `BL-10`…`BL-80`) і не має зовнішніх залежностей.

## Як зібрати і запустити тести

```bash
export JAVA_HOME=$(/usr/libexec/java_home -v 17)   # macOS; на Windows/Linux — JDK 17 у PATH
mvn -q -B test
```

Потрібні JDK 17 (Temurin) і Maven 3.9. Залежності (JUnit 5.10, Selenium 4.21) — ті самі, що у
стартовому проєкті пакета; UI-тести з тегом `ui` за замовчуванням не запускаються.

## Що всередині

Пакет `ua.kpi.tzyapz.eduportal` (`src/main/java`):

| Клас | Призначення | Вимоги |
|---|---|---|
| `GradeCalculator` | `weightedTotal(items)` — зважений підсумок курсу; `ectsLetter(total)` — літера шкали ECTS; `latePenalty(score, daysLate)` — бал після штрафу за запізнення | BL-10, BL-20, BL-30 |
| `QuizScorer` | `questionScore(question, selected)` — бал за питання (0..1); `score(answers, key)` — підсумок спроби у відсотках | BL-40, BL-50, BL-60 |
| `EnrollmentValidator` | `keyMatches`, `withinPeriod`, `hasCapacity`, `prerequisiteMet` — окремі умови; `violations(...)` — перелік порушених умов; `canEnroll(student, course, today, key)` — підсумкове рішення | BL-70, BL-80 |
| `GradeItem` (record) | елемент оцінювання: назва, бал 0..100, вага у відсотках | BL-10 |
| `QuizQuestion` (record) | питання тесту: ідентифікатор, варіанти, правильні варіанти | BL-40, BL-50 |
| `Student`, `Course` (records) | дані для перевірки зарахування: оцінки за складені курси; кодове слово, період зарахування, місткість, кількість зарахованих, передумовний курс | BL-70 |

Зразок тестів — `src/test/java/ua/kpi/tzyapz/eduportal/ExampleTest.java`.

## Реалізовані правила

- **BL-10.** Сума ваг елементів дорівнює 100, бали 0..100 — інакше `IllegalArgumentException`;
  підсумок = Σ бал × вага / 100, округлення до 2 знаків (HALF_UP).
- **BL-20.** Шкала ECTS: A ≥ 95; B 85–94; C 75–84; D 65–74; E 60–64; Fx 35–59; F < 35
  (межі трактуються як «від включно, до не включно»: B — 85 ≤ total < 95 тощо).
- **BL-30.** Штраф за запізнення: −10 % від балу за кожен день, максимум −50 %;
  округлення до 2 знаків.
- **BL-40.** Одна правильна відповідь: 1 бал, якщо обрано саме її, інакше 0; без відповіді — 0.
- **BL-50.** Кілька правильних: частка обраних правильних мінус частка обраних неправильних, не менше 0.
- **BL-60.** Підсумок спроби = сума балів / кількість питань у ключі × 100, округлення до 1 знака.
- **BL-70.** Зарахування можливе, коли одночасно: кодове слово збігається (з урахуванням регістру);
  дата у межах періоду зарахування включно; зараховано менше за місткість; передумовний курс
  складено з ≥ 60 балами.
- **BL-80.** `violations(...)` повертає коди порушень у порядку перевірки:
  `KEY`, `PERIOD`, `CAPACITY`, `PREREQUISITE`.

Дати — `java.time.LocalDate`; десяткові значення — `double` з округленням `BigDecimal` HALF_UP.
